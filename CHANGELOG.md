# Changelog

## 1.3.0 - 2026-09-22

- Added Vale as an automated documentation-prose quality gate in GitHub Actions.
- Added repository-specific terminology and word-choice rules plus a documented style guide.
- Updated the primary validation workflow to current GitHub Actions runtime versions and made error-level Vale findings merge-blocking.
- Added Vale configuration and style artifacts to the repository's required-file checks.

## 1.2.0 - 2026-09-22

- Added automated GitHub Pages publication of the browser-rendered OpenAPI reference.
- Added a documentation strategy and measurement framework covering information architecture, governance, contribution models, roadmap prioritization, quality, freshness, task success, support signals, and user feedback.
- Updated repository navigation and required-file quality checks for the new publishing and strategy artifacts.

## 1.1.0 - 2026-09-22

- Added a controlled AI-assisted documentation workflow covering authoritative sources, verification, human review, Git-based traceability, CI validation, and safe reuse of structured knowledge by AI-assisted systems.
- Added the workflow to repository navigation and automated required-file checks.

## 1.0.0 - 2026-09-22

- Initial portfolio release.
- Added entitlement discovery, access-request creation and retrieval, decision recording, and cancellation.
- Added OAuth 2.0 scopes, idempotency guidance, correlation IDs, reusable problem responses, and example payloads.
